# Local Video Reference Guide

The legacy admin catalog, server-hosted `videos` table, and catalog storage buckets have been removed.

The current workflow is:

1. Open **Add Video** from the roadmap dashboard.
2. Choose a video from the device media library.
3. Select or create a category and save a timestamped segment.
4. Edit the reference later from the roadmap or **Test Local Videos** screen.

Source video files remain on the device. Supabase stores reference metadata, categories, segments, notes, and completion state.
